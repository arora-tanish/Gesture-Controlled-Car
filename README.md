# Gesture-Controlled-Car
A gesture controlled car using arduino uno rev 3 and NRF24L01 modules.
Use code for both transmitter and the receiver along with an i2c scanner code (if the NRF24l01 does not show up in the serial monitor use this code for testing connection and the address) .
